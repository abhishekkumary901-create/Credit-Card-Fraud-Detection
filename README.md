# Credit Card Fraud Detection - CodSoft ML Internship Task 2

## Objective
To build a machine learning model to detect fraudulent credit card transactions.

## Dataset
Credit Card Fraud Dataset (284807 transactions from Kaggle)

## Tech Stack
- Python
- Pandas, Numpy
- Scikit-learn
- Google Colab

## Model Used
Logistic Regression

## Result
- Accuracy: 99.85%
- Model successfully classifies Fraud vs Non-Fraud transactions.
